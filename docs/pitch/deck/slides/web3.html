Demo 2 · Web3 gated mint

One transaction: verify, record, mint.

Proof bound to the wallet

Same card again → Already claimed

Card from another prefecture → rejected by the gate

The proof is bound to the wallet. zk_gate verifies Groth16 with the alt_bn128 syscalls, stores the nullifier in a PDA and mints a Metaplex Core NFT in one transaction, about 144k compute units. Then: the same card again is rejected as already claimed; a card from another prefecture is rejected by the gate policy.
