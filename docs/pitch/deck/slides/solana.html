Why Solana? It gives us a shared "one per person" registry that no company has to own. Verifying the Groth16 proof with the alt_bn128 syscalls, recording the nullifier and minting the NFT all fit in one transaction, about 144k compute units. Each card leaves a per-gate nullifier, so a second claim simply fails on-chain — and nobody keeps a list of people. The trusted government CA keys live on-chain too, so any website can read the same trust list; our Web2 store does exactly that. Next: the Solana Attestation Service for reusable credentials, and x402 so an AI agent can show there is a verified human behind it.
